# Employeflow: employee folders (replaced)

Since plugin 0.4.0 every employee gets its own session with /employeflow:start: it makes the employee's folder, names
the session after them and files it under the team in the sidebar. Tell the user in one line: "This is now part of
/employeflow:start: open a new Code session for each employee and type /employeflow:start there." Create nothing.
